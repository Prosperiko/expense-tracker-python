
# Expense Tracker CLI

A lightweight Command Line Interface (CLI) application built with Python to help users manage their daily spending. 

This project demonstrates core Python concepts, including:
* Dictionaries and Lists for data structuring.
* The `json` module for file operations.
* Data persistence across application restarts.

## Features
* **Add Expense**: Easily input the description and cost of an item.
* **View All**: See a formatted list of all your recorded expenses, alongside the total amount spent.
* **Persistence**: All your data is automatically saved to an `expenses.json` file. If you close the program and return later, your data will still be there.

## Prerequisites
* Python 3.x installed on your machine.
